# NASA resources used by this project

Use the resource names as the submission form's Link Text.

| Resource name | Official link | Project use |
|---|---|---|
| SPHEREx Data Release 1 Spectral Images | https://irsa.ipac.caltech.edu/data/SPHEREx/docs/overview_dr1.html | Calibrated IMAGE pixels, observation metadata and native wavelength information |
| SPHEREx Quick Release 3 Spectral Images | https://irsa.ipac.caltech.edu/data/SPHEREx/docs/overview_qr.html | Additional spectral-image observations and metadata |
| NASA/IPAC IRSA Simple Image Access v2 API | https://irsa.ipac.caltech.edu/ibe/sia.html | Coordinate/time-based discovery of archive image products and access URLs |
| SPHEREx Archive User Guide — Data Access | https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-access/ | Collections, data organization and retrieval methods |
| SPHEREx Explanatory Supplement | https://irsa.ipac.caltech.edu/data/SPHEREx/docs/SPHEREx_Expsupp.pdf | Data-product and calibration documentation |
| IRSA SPHEREx Spectral Image Cutouts Tutorial | https://caltech-ipac.github.io/irsa-tutorials/spherex-cutouts/ | Reference for image-region access and target-position wavelength metadata |
